# Polices embarquées

Toutes sont publiées sous **SIL Open Font License 1.1**, qui autorise leur
redistribution avec ce projet. Texte complet : <https://scripts.sil.org/OFL>

| Fichier | Police | Auteurs |
|---|---|---|
| `Anton-Regular.ttf` | Anton | Vernon Adams, Cyreal |
| `ArchivoBlack-Regular.ttf` | Archivo Black | Omnibus-Type |
| `BebasNeue-Regular.ttf` | Bebas Neue | Ryoichi Tsunekawa, Dharma Type |
| `PlayfairDisplay-Bold.ttf` | Playfair Display | Claus Eggers Sørensen |

Elles sont embarquées pour que les sous-titres aient le même rendu sur toutes
les machines : sans elles, ffmpeg retombe sur une police système quelconque et
le résultat perd tout son caractère.
